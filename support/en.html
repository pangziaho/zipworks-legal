Common questions

Which formats are supported?

Extract: ZIP and ZIPX (including ZIP64 and password-protected ZIP), RAR (RAR4 and RAR5, encrypted and split), 7Z (including encrypted file names), TAR, GZ/TGZ, BZ2, XZ, ZST, LZ4, LZMA, LZ, Z, ISO, CAB, LZH/LHA, CPIO, XAR/PKG, AR/DEB, RPM, CBZ/CBR/CB7, and ZIP-based files such as JAR, APK and IPA. Create: ZIP (with AES-256 or Windows-compatible encryption), 7Z (with AES-256), TAR, TAR.GZ, TAR.BZ2, TAR.XZ and TAR.ZST. RAR archives can be opened but not created.

Where are my extracted files?

By default, in the same folder as the archive. You can change this in Settings › Extract To. All files are also visible in the Files app under On My iPhone › ZipWorks.

File names look garbled.

Archives made on older Windows computers store names in a local encoding. ZipWorks detects Chinese (GBK, Big5), Japanese (Shift_JIS) and Korean names automatically. If a name is still wrong, open the archive, tap ⋯ › Filename Encoding and pick another one.

How do I open a split archive?

Put all parts in the same folder (for example Movie.part1.rar, Movie.part2.rar… or Archive.7z.001, .002…; .r00 and .z01 also work) and open any part. If a part is missing, ZipWorks tells you which one.

How do saved passwords work?

When you enter a password you can save it to the Password Book. The next time you open an encrypted archive, saved passwords are tried automatically. Manage them in Tools › Password Book.

How do I make a password-protected ZIP that Windows can open?

When compressing, turn on Set Password and choose “Compatible with Windows Explorer”. AES-256 is stronger but needs a tool that supports AES. If the recipient uses an older Windows with Chinese or Japanese file names, also choose the matching Filename Encoding.

How does Wi-Fi Transfer work?

Connect the computer and your device to the same Wi-Fi, open Tools › Wi-Fi Transfer, and type the address shown into the computer's browser. Keep the screen open while transferring.

Can I open files from Google Drive, Dropbox or OneDrive?

Yes. Install their app and turn it on in the Files app, then tap Import in ZipWorks and choose the service. You can also share a file to ZipWorks from those apps.

How do I sync with my other devices?

Turn on iCloud Drive in the Cloud tab. Files in the iCloud Drive location sync to your other devices and appear in the Files app under iCloud Drive › ZipWorks.

Does extraction continue in the background?

On iOS 26 and later, yes, with progress shown by the system. On earlier versions iOS allows only a short time in the background, so keep ZipWorks open for very large archives.
